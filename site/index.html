Send to the GanderData database

GanderData is the shared database behind the Gander addon: what each mob casts, and its stats. This page sends what your game has learned to it.

Your logs stay on this computer. The page reads them here, in your browser. Only mob names, spell names, stats, counts and the time spent in each dungeon are sent. No player's name is.

Stats from Gander

Type /gander send in game, copy the block it shows, and paste it here. It is sent as soon as you paste it.

Combat logs: what mobs cast

Drop your Logs folder or log files here

With the button: go to the Logs folder, press Ctrl+A and Open. The window shows only combat logs. The game keeps its other logs in that folder too; this page never opens those.

The folder is World of Warcraft\_forever_\Logs for Forever and World of Warcraft\_classic_era_\Logs for Classic Era. The game only writes a log while logging is on: tick it in Gander's settings, or type /combatlog.

The database keeps track of which logs it has had, so you can drop the whole folder every time: a log is never counted twice, whoever sends it.
